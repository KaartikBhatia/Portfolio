The Maker Side


This page is a collection of some physical projects I created, feel free to explore!

    Spotify Car Thing- I reused an old, bricked Spotify CarThing and turned it into a carplay device using Prelude, an open source mod to turn CarThing into a device that can run Apple Carplay and can be installed into any older vehicle to add modern capabilities.

    QuizBot - This was a project for my CCP Engineering 1 class, and it involved me using a Raspberry Pi 4b and a touchscreen to create a device that uses Ollama to read a USB drive and generate a 10 question quiz on any topic. The device functions completely offline, and is meant to be a solutions for students with limited to no internet access.
