# Kaartik Bhatia's Personal Portfolio website

This is a personal portfolio website made using Flask, HTML, CSS, and Python. It is to showcase my programming and educational achievemnts, skills, and recognizations.

# Languages Used

Python
Flask
HTML
CSS

# Run Locally

1) First, run git clone https://github.com/KaartikBhatia/Portfolio.git to clone this repo to your computer, and then run cd Portfolio to go inside the Portfolio folder where the code is.

2) Run pip install -r requirements.txt to install all required packages.

3) Run python app.py to start the app, and go to the local URL printed in the console.
